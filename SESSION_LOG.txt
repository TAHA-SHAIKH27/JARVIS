HOW TO RUN
----------
```bash
conda activate jarvis
python start_jarvis.py
# Opens: http://localhost:3000 (or 3001)
```

USAGE
-----
1. Click mic button (top bar) → turns green/blue
2. Browser asks for mic permission → Allow
3. Core sphere turns BLUE (listening)
4. Say "Hey Jarvis" → beep plays, sphere flashes GREEN
5. Speak command → sphere turns AMBER (processing)
6. JARVIS replies → sphere GREEN (speaking) → back to BLUE
7. Click mic again to stop

ARCHITECTURE
------------
Browser (WebSocket) → Backend (/api/voice/stream) → openwakeword + faster-whisper → process_command() → response → Browser TTS
